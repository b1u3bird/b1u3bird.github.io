背景

当多个线程读写同一份状态时，真正需要关注的不只是变量本身，还有写入何时对另一个线程可见。这个问题通常落在编译器优化、CPU 缓存和语言内存模型之间。

模型

一个实用的判断方式是先找到同步边界：锁释放到锁获取、volatile 写到 volatile 读、线程启动和线程结束等。边界之外的数据传播不能靠直觉保证。

代码

class Counter {
    private volatile int value;

    int get() {
        return value;
    }

    void set(int next) {
        value = next;
    }
}
