# Suggested Commands

- Static HTML preview: open `D:\Code\website\index.html` directly in a browser when no server-only features are used.
- Optional lightweight server from project root if needed: `python -m http.server 8000`.
- Windows directory listing from project root: `dir` or PowerShell `Get-ChildItem`.
- Search files/content with `rg --files` and `rg <pattern>` when available.
